# Practical software for your business workflow

I'm Edward Aming, CTO at Smaroot (慧根智研), a software development company based in Beijing, China. We help businesses improve existing applications and connect the tools they already use.

## What we can help with

- **App fixes:** a reproducible failure in an existing web application, data flow or permission module.
- **API and CRM integrations:** one clear trigger, the required output, retry handling and a testable handover.
- **AI workflows:** task orchestration, human approval and execution records for a defined business process.
